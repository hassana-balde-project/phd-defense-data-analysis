# PhD Defense Data Analysis

## Overview

This project analyses a dataset of PhD defenses in France using R. The objective was to clean, process and analyse the data and identify patterns and trends in PhD defenses over time.

## Main tasks

* Data cleaning and preprocessing
* Handling missing values
* Data manipulation and aggregation
* Statistical analysis
* Date and text processing
* Data visualization

## Tools

* R
* R Markdown
* dplyr
* ggplot2
* lubridate
* stringr
* naniar

## Skills Demonstrated

This project demonstrates my skills in data management, statistical analysis, data visualization and R programming.

## Data

The original dataset is not included in this repository. The repository contains the R Markdown code used for the analysis.
